# 结构实验室

中文 React / Vite 数据结构可视化应用。独立项目，不修改或提交原 GitHub 仓库。所有数据保存在当前页面内存中，刷新恢复示例。

## 启动

安装 Node.js 20.19+ 或 22.12+（建议 LTS），在本目录打开终端：

```sh
npm install
npm run dev
```

浏览器打开终端显示的本地地址，默认 http://127.0.0.1:5173 。

```sh
npm test        # 算法与边界测试
npm run build  # 生成 dist
npm run preview # 预览构建产物
```

支持 npm，也可使用 pnpm。已附 npm 锁文件。运行无需 C 编译器、后端或 GitHub 登录。可将 dist 部署到静态服务器。不要直接双击 dist/index.html；应通过 HTTP 访问。

## 操作方式

1. 左侧选择结构，在右侧选择操作和参数，点击“执行操作”。位置从 1 开始，下标从 0 开始。
2. 播放 / 暂停、上一步、下一步、时间线拖动与速度选择控制当前操作。
3. 操作结束后，可以在结果上继续操作；回看中间状态时先回到最后一步，或者重置示例。
4. 重置按钮恢复当前模块的初始示例。切换模块也会恢复该模块示例。
5. 二叉树输入逗号分隔的数组，最多 31 个数，-1 表示空节点；点击“重新建树”。
6. “源码对应”包含锁定提交版本的原文件链接与语义说明。

## 与原 C 实现的边界

- 这是独立 JavaScript 教学移植，不执行原 C 二进制，不模拟真实内存地址。
- 线性表按值搜索为明确标注的教学扩展；原 locateList 是按位置读取。
- 为浏览器可视化补充边界与整数校验，线性结构演示容量统一限制为 100。原 C 的无效指针、缺失空栈检查与分配缺陷不复现。
- 单/双链表的连接修改以节点高亮、分阶段说明与最终连接图表达；不展示中间的悬空指针。
- 双向链表遵循 node_at 的选择规则：position <= length/2 从头开始，否则从尾开始。
- 队列忠实呈现原数组移位语义，并非循环队列。原 GetFront 读取 elem[rear]（最新元素）有误，本应用按 FIFO 显示 elem[front-1]（最早元素），界面中注明修正。
- 二叉树是普通二叉树，不是 BST；空节点的后代不可达。建树是一次性替换，遍历与统计可逐步播放。
- 哈希碰撞直接覆盖，未实现原仓库 TODO 中的冲突处理。不提供单键删除；清空对应 destroy 后重新初始化。键限 1–24 个可见 ASCII 字符，规避 C char 的非 ASCII 平台差异。
- 遍历伪代码是教学摘要，实际前、中、后序由独立引擎生成；未将伪代码冒充原 C 逐行调试。
- Google 字体是可选外部资源；不可访问时自动使用本地中文字体。所有功能和绘图均不依赖外部服务。

- src/engine.test.js：算法和边界测试
